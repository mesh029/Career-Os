## Scope (the JD is unusually broad — it is the union of everything)

**Servers and systems:** install, configure, monitor, maintain physical and virtual servers; operating systems, system software, enterprise applications; performance, availability, reliability; upgrades, patches, maintenance; capacity monitoring; backup and disaster recovery; cloud infrastructure where applicable.

**Network:** LAN, WAN, VPN, Wi-Fi, internet connectivity, network security devices; routers, switches, firewalls, appliances; network performance monitoring and connectivity troubleshooting; network security and ICT policy compliance; IP addressing, DNS, DHCP.

**Data centre:** data centre facilities and ICT equipment; server health, storage, **UPS, environmental controls**; documentation of data centre assets and configurations; preventive maintenance and vendor support; business continuity and DR.

**Support:** **second-level and third-level** support; hardware, software and systems troubleshooting; user accounts, permissions, access controls; business application support; escalation to vendors.

**Incidents:** resolve within **agreed service levels**; root cause analysis and preventive measures; incident logs, reporting and closure; major incident response; operational procedures for incident handling.

**Security:** implement and enforce ICT security controls and policies; monitor system logs and security alerts; endpoint protection, vulnerability assessments, patch management; cybersecurity awareness; security audits and risk assessments.

**Projects:** planning, implementation and deployment of ICT projects; infrastructure project coordination; technical documentation and implementation plans; system migrations, upgrades, new technology deployments; internal stakeholders and external vendors.

**Training and mentoring:** ICT user awareness and training; user guides, technical documentation, SOPs; **mentor junior ICT staff**; promote best practice.

**Vendors and assets:** coordinate vendors and service providers; monitor service contracts and support agreements; accurate **ICT asset and licence inventory**; procurement evaluations.

**Documentation and governance:** system, network and infrastructure documentation; periodic reports on system performance, incidents and infrastructure health; change and configuration documentation; **ICT governance and audit compliance**.

## Requirements

- Bachelor's degree in Computer Science, IT, System Engineering or related field
- **3+ years active experience in system and network administration**
- Certifications **strongly preferred**: MCSA/MCSE, **CCNA**, CompTIA Network+/Security+
- Hands-on: **Windows Server, Linux, Active Directory, virtualisation (VMware/Hyper-V), cloud (AWS/Azure/O365)**
- Strong knowledge of **network security, firewalls, backup solutions**
- Strong diagnostics, attention to detail, works under pressure on urgent incidents
