## Key Responsibilities
- Oversee the hotel's entire IT infrastructure: LAN/WAN, servers, cloud systems, backup solutions, guest/staff Wi-Fi.
- Manage specialized hospitality software: Property Management Systems (PMS), Point of Sale (POS), keycard locking systems.
- Implement cybersecurity measures, firewalls, data protection protocols; oversee CCTV, access control, IP telephony.
- Provide timely technical support to all departments; minimize downtime for guest-facing tech (in-room entertainment, conference/AV).
- Manage relationships with external IT vendors, service providers, ISPs; keep accurate inventory of hardware, software licenses, IT assets.
- Advise management on technology upgrades, IT budgeting, and innovation to improve efficiency and guest satisfaction.

## Qualifications & Experience
- Bachelor's in Computer Science, IT, or related field.
- Proven experience as an IT Manager or similar leadership role (preferably hospitality).
- Professional certifications highly desirable.
- Hands-on with hotel systems (PMS, POS, keycard). Strong network management, security, troubleshooting.
- Problem-solving, leadership, ability to work under pressure in a 24/7 environment.
