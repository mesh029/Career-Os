## Likely interview questions

**How would you keep clinical systems available 24/7 across 15 sites?**
Redundancy where an outage would stop care, monitoring that tells me before users do, capacity watched as a trend rather than an alarm, and a change window that never lands mid-clinic. Then documentation, so the next person can restore it without me.

**A site loses connectivity at 2am. Walk me through it.**
Confirm scope first — one site or several, which tells me link or core. Check the monitoring and the device status, then the path: power, switch, router, ISP handoff. Fail over if there is a secondary link, get the ISP on the phone with a ticket number, and keep the clinical team informed while I work. Root cause and documentation the next morning.

**How do you work with a Cyber Security team?**
They set the policy, I implement and operate it on the network — segmentation, firewall rules, access control, patching — and I feed back what breaks clinical workflow so the control gets adjusted rather than bypassed.

**Biomedical and IoT devices on the network?**
Own VLAN, tight access control, only the traffic they need, documented addressing. Most of those devices cannot defend themselves, so the network has to.
