## About the role
Manage and support Gas Africa's technology infrastructure. Hands-on systems administration, network management, and technical support. Reports to senior IT management; works with staff across departments; direct responsibility for mission-critical infrastructure.

## Key Responsibilities
- Administer and maintain all ICT systems, hardware, software, and network infrastructure for continuous uptime.
- Deliver technical support to end users; diagnose faults; resolve issues promptly.
- Implement data security measures, manage system backups, oversee timely software updates.
- Create/maintain user accounts, track ICT assets, keep system documentation current.
- Monitor network performance; conduct routine maintenance to prevent failures.
- Collaborate with external vendors and service providers for specialist support.

## Requirements
- Bachelor's in IT, Computer Science, or related (Diploma + substantial experience considered).
- Demonstrable experience in ICT support and network administration.
- Solid knowledge of Microsoft 365, network infrastructure, and cybersecurity fundamentals.
- Proven independent troubleshooting of complex technical issues.
- Strong communication (explain technical concepts to non-technical staff).
- Manage multiple tasks and prioritise in a busy environment.
