## Key responsibilities

- Prepare and configure computers, including Windows OS, drivers, and network settings
- Install and configure Microsoft 365 and business applications per installation guides
- Create and manage Windows and Microsoft 365 user accounts
- Identify and troubleshoot basic hardware and electrical issues
- Maintain IT asset inventory and assignment records
- Diagnose network issues using Ping, Tracert, and DNS resolution tools
- Support equipment deployment and relocation across business locations
- Document and close tickets in the ITSM platform following IT procedures

- Understanding of LAN/WAN networking principles and protocols
- Knowledge of hardware troubleshooting and computer configurations
- Familiarity with ITSM practices and ticketing systems
- Strong problem-solving and communication skills
- Customer-focused and detail-oriented mindset
