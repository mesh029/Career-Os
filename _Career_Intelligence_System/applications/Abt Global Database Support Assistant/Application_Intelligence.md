## Likely interview questions

1. How would you run and act on a daily DHIS2 duplicate report? Walk through: export, sort by household/structure ID and date, confirm true duplicates vs revisits, send the list to the site MEL assistant, update after feedback, re-run next day.
2. What is an outlier in spray data? Example: one operator reporting far more structures sprayed per day than the team average, or rooms sprayed greater than rooms found. Check against the team leader's form before changing anything.
3. How do you verify submissions per spray operator? Daily count per operator ID compared with the team leader's summary; flag gaps the same day.
4. A field team says data was submitted, but you cannot see it. What do you check? Device sync status, unsent forms, network, correct server or project, correct org unit, then escalate.
5. How do you protect paper forms and data? Filed by date and site, locked storage, access only for MEL staff, no copies on personal devices.
