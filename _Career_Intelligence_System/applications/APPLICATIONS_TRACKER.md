## ATS scoring key

| Column | Meaning |
|---|---|
| **Format** | Will the ATS parser read the CV cleanly? (layout, fonts, structure) |
| **Keywords** | % of JD terms truthfully present in the tailored CV |
| **Quals** | Degree, years, certs vs hard requirements |
| **Experience** | Depth of evidence for day-to-day duties |
| **Human** | Likelihood a recruiter shortlists after ATS (gut + gaps) |
| **Apply** | Overall weighted recommendation (not a job offer predictor) |

**Weights for Apply score:** Keywords 35% + Quals 20% + Experience 25% + Format 10% + Human 10%.
