# Technical Support Agent — reusable base

*Not a single employer posting. Use this pack as the default CV when the job is Technical Support Agent, Technical Support Specialist, Product Support, SaaS L1/L2, or similar. Clone the folder and retarget the cover when you have a named company.*

## What these jobs usually want

- 1st and 2nd line: tickets, live chat, email, remote sessions
- Reproduce the issue, isolate the layer (account, device, network, application), close or escalate with notes
- Identity and endpoints: passwords, MFA, Microsoft 365, Windows
- Read a web or mobile product well enough to tell engineering what broke
- Knowledge base, SLA, ITIL-shaped queues (Freshdesk, Zendesk, Jira, Zoho)
- Calm English with non-technical users

## What this CV leads with

Service desk first. Application-layer diagnostics second. Systems internals as the reason you do not guess from the ticket title.

Do not send this pack to a pure hardware-only desktop job if they will punish programming. Do send it to SaaS, BPO, MSP L2, Influx-style, Pavago-style, and any posting that mentions troubleshooting apps, APIs, or talking to engineering.
