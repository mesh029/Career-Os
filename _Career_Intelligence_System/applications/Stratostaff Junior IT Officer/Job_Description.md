## Key responsibilities

**IT support and troubleshooting.** Provide first-line technical support. Diagnose and resolve hardware, software, network and user-access issues. Escalate complex incidents.

**Systems and network administration.** Day-to-day administration of computers, network infrastructure, user accounts, Microsoft 365, Google Workspace and other business applications. Reliable system availability.

**IT asset and user management.** Accurate IT asset and equipment registers. Device configuration and deployment. User onboarding and offboarding. Appropriate access rights.

**Cybersecurity, backup and data protection.** Routine security controls, software updates, antivirus, backups and access-management. Support compliance with IT and data-protection requirements.

**IT operations, monitoring and documentation.** Monitor IT systems. Maintain service and incident records. Document recurring issues and solutions. Basic IT reports. Improve reliability and user productivity.
