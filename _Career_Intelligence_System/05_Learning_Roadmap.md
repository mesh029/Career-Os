# Skills Worth Learning — ROI-Ranked Roadmap

*Governed by `00_SYSTEM_PROMPT.md`. Ranked by return on investment for YOUR trajectory (health informatics + INGO IT + remote). Re-scored as the market moves.*

Scoring key: Effort (low/med/high) · Salary impact · Interview impact · Remote-hiring impact (each ★–★★★).

---

## Tier 1 — Do these next (highest ROI, directly unlock target roles)

### 1. HL7 / FHIR fundamentals (interoperability)
- **Why:** The #1 recurring requirement in health-IT/EMR job descriptions you don't yet have. Converts you from "EMR support" to "interoperability-literate." Global + remote demand.
- **Effort:** Med · **Salary ★★★ · Interview ★★★ · Remote ★★★**
- **How:** HL7 FHIR "Fundamentals" (HL7.org), free FHIR intro courses, OpenMRS FHIR module docs. Build one repo that reads/writes FHIR resources.
- **Proof:** GitHub repo + a LinkedIn post explaining FHIR simply.

### 2. DHIS2 Academy / Fundamentals certificate
- **Why:** Formalizes what you already do; recognized across the entire African digital-health sector.
- **Effort:** Low–Med · **Salary ★★ · Interview ★★★ · Remote ★★**
- **How:** DHIS2 Academy (online, academy.dhis2.org) — Fundamentals + Data Quality or Analytics track.

### 3. Power BI / Data Analytics credential (PL-300 or Google Data Analytics)
- **Why:** Turns your dashboard work into a credential; opens the higher-paid "health data analyst" lane.
- **Effort:** Med · **Salary ★★★ · Interview ★★ · Remote ★★★**
- **How:** Microsoft PL-300 (Power BI Data Analyst) or Google Data Analytics (Coursera). You already have "Microsoft Data Analysis."

### 4. ITIL 4 Foundation
- **Why:** You already work ITIL/SLA — this certifies it cheaply and is expected for INGO/enterprise IT roles.
- **Effort:** Low · **Salary ★ · Interview ★★ · Remote ★★**

## Tier 2 — Within 6 months (deepen the moat)

### 5. OpenMRS / Bahmni / Ozone HMIS depth + Docker
- **Why:** OpenMRS underpins KenyaEMR; being able to stand one up (Docker) and navigate modules is a strong implementation signal.
- **Effort:** Med · **Salary ★★ · Interview ★★★ · Remote ★★★**
- **How:** Run OpenMRS locally via Docker; document setup; learn the data model + reporting module.

### 6. SQL depth (windowing, performance, health data models)
- **Why:** Your analytics ceiling. Strong SQL is the difference between "runs queries" and "owns the data."
- **Effort:** Med · **Salary ★★ · Interview ★★ · Remote ★★**

### 7. Python for data (pandas + APIs)
- **Why:** Automates DHIS2/EMR extracts and validation; pairs with FHIR and dashboards.
- **Effort:** Med · **Salary ★★ · Interview ★★ · Remote ★★★**

### 8. Cloud step-up: Azure AZ-104 or AWS Solutions Architect Associate
- **Why:** For infra/ops/remote-sysadmin variant; moves you beyond AZ-900.
- **Effort:** High · **Salary ★★ · Interview ★★ · Remote ★★★**
