# Stretch packs

Hard-positioned CVs for roles that are a title stretch. Intern off when it weakens the screen. Independent projects and consulting carried on the page. PATH employer titles stay canonical so referees still match.

Not the same as `applications/`. Standard ICT applies stay there.

```
stretch/Employer Role/
  Job_Description.md
  Application_Intelligence.md
  build.py
  Portal_Application_Pack.md  (if the channel needs it)
  Meshack Ariri CV.pdf / .docx
  Meshack Ariri Cover Letter.pdf / .docx
```

Rebuild from repo root of the career system:

```
python3 "stretch/Simera Project Coordinator/build.py"
python3 "stretch/Simera Project Assistant/build.py"
python3 "stretch/G Adventures Tour Staff Administrator/build.py"
python3 "stretch/Wave HR Systems Analyst/build.py"
python3 "stretch/Tier 3 IT Support NOC Engineer/build.py"
```

Apply copies: `downloads/JOBS/stretch/`
