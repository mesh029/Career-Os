# Tier 3 IT Support & NOC Engineer

*Captured 2026-09-10 from the posting Meshack pasted. Employer name not in the paste. Update the cover greeting when the company is known.*

## Role overview

Highly skilled Tier 3 IT Support & NOC Engineer. Networking, infrastructure, monitoring, advanced troubleshooting. Escalation point for Tier 1 and Tier 2. Mix of Network Operations, IT Support, Systems Administration, and Security. Availability, stability, performance, and security of critical IT environments.

Diagnose and resolve high-impact incidents, monitor infrastructure, perform RCA, implement network changes, drive continuous improvement. Stack named: Microsoft 365, Azure/Entra ID, Active Directory, Windows/macOS, firewalls, VPNs, SD-WAN, network monitoring, automation. Collaborate with technical teams, vendors, and field technicians.

## Key responsibilities

- Monitor infrastructure using SolarWinds, PRTG, Nagios, Zabbix, Cosmos, and other platforms
- Diagnose and resolve complex network, infrastructure, system, and connectivity issues
- Primary technical escalation for Tier 1 and Tier 2
- Advanced troubleshooting and Root Cause Analysis (RCA)
- Troubleshoot LAN, WAN, MPLS, SD-WAN, and wireless
- Diagnose routing and switching: BGP, OSPF, EIGRP, STP
- Configure and manage routers, switches, firewalls, VLANs, VPNs, wireless controllers, load balancers
- Analyze traffic with Wireshark and tcpdump
- DNS, DHCP, NAT, VoIP, QoS
- Windows, macOS, Active Directory, Azure/Entra ID, Microsoft 365
- Automation with PowerShell and RMM
- Firmware upgrades, patching, configuration changes
- Security events, logs, SIEM/EDR alerts
- Coordinate vendors, specialized teams, field technicians
- Technical documentation, network diagrams, SOPs, incident reports
- Disaster Recovery, security, capacity planning, continuous improvement

## Requirements

- 2+ years Network Operations, NOC, Infrastructure Support, or similar
- Advanced network and infrastructure troubleshooting
- TCP/IP, VLANs, QoS, DNS, DHCP, NAT
- BGP, OSPF, EIGRP, STP
- Cisco, Ruckus, Aruba/HP, and/or Meraki
- Firewalls: Cisco ASA, Fortinet, and/or WatchGuard
- Monitoring: SolarWinds, PRTG, Nagios, or Zabbix
- VPN, SD-WAN, LAN/WAN, wireless
- Windows, macOS, AD, Azure/Entra ID, Microsoft 365
- Incident management, escalations, RCA
- 24/7 operations and on-call
- Bachelor's in CS/IT or equivalent

## Preferred

- MSP environment
- PowerShell and RMM
- SIEM, EDR, network security
- PMS or hospitality technology
- Coordinating field technicians and vendors
- CCNA, CCNP, Aruba, Ruckus, Meraki, Network+, CWNA, Fortinet NSE
