- Remote SysAdmin with Azure/AWS deep requirements → apply if they accept AZ-900 + learning
- CRM / Zoho / HubSpot support → only if JD is support/admin, not sales
- Data support / reporting assistant → if SQL/Excel/Power BI appear
- Web / WordPress light ops → only "maintain existing site," not "hire a developer"

### SKIP even when jobless (wastes time + damages brand)

- Pure sales / SDR / cold calling
- Talent acquisition / HR / recruiting
- Pure voice CX with no technical tools
- Senior DevOps / SRE / software engineer (you'll fail screens)
- Cybersecurity analyst / SOC (unless explicitly junior + your hackathons are enough — rare)
- Roles requiring "must be in US/EU with work authorization" you don't have
- Anything you cannot defend in a 15-min screen with PATH evidence

### The 60-second browse rule

Open a JD → count how many of these you can truthfully claim from PATH/freelance:

1. Ticketing / SLA / ITIL  
2. Microsoft 365 / Google Workspace  
3. Active Directory / user access  
4. Windows / endpoint support  
5. Networking / VPN / Wi-Fi basics  
6. Remote troubleshooting / documentation  
7. Linux or servers (bonus)  
8. SQL / dashboards / reporting (bonus)  
9. Training / onboarding users (bonus)  
10. Uptime / multi-site / 100+ users (bonus)

**≥5 matches → apply same day.**  
**3–4 → apply only if remote + easy apply and you have energy.**  
**<3 → skip.**
